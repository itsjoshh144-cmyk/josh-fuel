# Josh's Fuel ⚡

Mobile-first high-protein meal guide (PWA). Today's meals, 18 recipes, Sunday batch-prep plan, Aldi/Lidl shopping list and a daily protein tracker. No login, works offline after first load.

Edit meals, plan, prep steps and shopping list in `data.js`. Bump `VERSION` in `sw.js` after changes so phones pick up the update.
